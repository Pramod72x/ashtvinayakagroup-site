Minimal single-page site for www.ashtvinayakagroup.in

Files:
- index.html — homepage
- CNAME — custom domain (www.ashtvinayakagroup.in)

To publish on GitHub Pages:
1. In this repo go to Settings → Pages.
2. Under Source choose branch "main" and folder "/ (root)" and Save.
3. Ensure Custom domain is set to "www.ashtvinayakagroup.in" (the CNAME file is already present).
4. After DNS propagates, check "Enforce HTTPS".

DNS to add at your registrar (paste exactly):
- Type: CNAME
- Name/Host: www
- Value/Target: Pramod72x.github.io

Do NOT change or remove your existing MX/TXT records (email).
